Syncs export JPEG metadata from matching originals and renames files to source names.

Fills missing GPS coordinates by copying from nearest-in-time donor photos (default gap: 2 hours).

Extracts EXIF metadata and builds a concise summary written to comment/description tags. Runs on all JPG/JPEG files in the target folder. Requires GEOCODIO_API_KEY env var for reverse geocoding.

No additional options -- processes all JPG/JPEG files in the target folder.

Generates photo descriptions via Ollama LLM and writes them to EXIF/IPTC metadata.

Generates photo keywords via Ollama LLM and writes them to IPTC keyword tags.

Detects blur via ImageMagick, splits photos into scenes, selects the sharpest frame per scene.

Scene break threshold

Renames photos to YYYYMMDD-HHMMSS-camera-location.ext using EXIF + reverse geocoding. Requires GEOCODIO_API_KEY.

Renames GoPro MP4 clips to YYYYMMDD-HHMM-location-duration-original.mp4. Requires GEOCODIO_API_KEY.

No additional options -- processes all MP4 files in the target folder.

Generates a contact/proof sheet with metadata captions.

Split into numbered sheets when set (e.g. proof_1.jpg, proof_2.jpg)

Clears selected EXIF/IPTC fields. Defaults: UserComment, ImageDescription, Caption, Caption-Abstract, Keywords.
