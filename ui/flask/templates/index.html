Creates a standardized folder hierarchy for a new photo project based on your equipment configuration.

Syncs export JPEG metadata from matching originals and renames files to source names.

Fills missing GPS coordinates by copying from nearest-in-time donor photos (default gap: 2 hours).

Geocodes a location name via Geocod.io and writes GPS coordinates to photo EXIF. Optionally randomizes coordinates within a radius for natural distribution. Requires GEOCODIO_API_KEY environment variable.

Extracts EXIF metadata and builds a concise summary written to comment/description tags. Runs on all JPG/JPEG files in the target folder. Requires GEOCODIO_API_KEY env var for reverse geocoding.

No additional options -- processes all JPG/JPEG files in the target folder.

Generates photo descriptions via Ollama LLM and writes them to EXIF/IPTC metadata.

Generates photo keywords via Ollama LLM and writes them to IPTC keyword tags.

Generates a short headline via Ollama LLM and writes it to the IPTC Headline field. Skips files where the headline is already populated.

Detects blur via ImageMagick, splits photos into scenes, selects the sharpest frame per scene.

Scene break threshold

Renames photos to YYYYMMDD-HHMMSS-camera-location.ext using EXIF + reverse geocoding. Requires GEOCODIO_API_KEY.

Renames GoPro MP4 clips to YYYYMMDD-HHMM-location-duration-original.mp4. Requires GEOCODIO_API_KEY.

No additional options -- processes all MP4 files in the target folder.

Generates a contact/proof sheet with metadata captions.

Split into numbered sheets when set (e.g. proof_1.jpg, proof_2.jpg)

Find and replace text in selected EXIF/IPTC metadata fields. Keywords are handled individually — replaces the matching keyword, not the entire list.

Click Discover to see which fields have data, or type field names below.

Batch-writes photographer name, copyright notice, and contact info to IPTC/EXIF fields. By default only fills empty fields — enable Force to overwrite. Use %Y in the copyright field for the current year.

Uses Ollama to read all descriptions across a photo set and detect outliers — wrong event names, location mismatches, tone differences. Report-only by default. Enable Fix to auto-correct inconsistencies.

Keeps the SQLite photo catalog in sync with the folder contents. Creates the catalog if it doesn't exist. Prunes entries for deleted files, then indexes any new files. Enable Rebuild to drop and recreate from scratch.

Clears selected EXIF/IPTC fields. Defaults: UserComment, ImageDescription, Caption, Caption-Abstract, Keywords.

Leave blank for unlimited when recursive is checked
