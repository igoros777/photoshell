## Vision

### 10x Check
The 10x version of PhotoShell is a local-first photo workflow platform that rivals Lightroom's organizational capabilities with the power-user density of DaVinci Resolve. A photographer returns from a multi-camera trip, drops folders onto the UI, and watches the entire pipeline execute across all camera folders simultaneously — GPS filling, blur detection, AI annotation, renaming — with a live map showing photo locations populating in real-time, a pipeline flowchart pulsing as steps complete, and before/after comparisons for every destructive operation with one-click undo.

## Architecture Decisions
1. **Implementation approach:** Phased Monolith (build on existing Flask+jQuery)
2. **JS organization:** Split into feature-specific files (map.js, pipeline.js, etc.)
3. **Multi-folder execution:** Per-folder sequential (process folder A fully, then B, then C)
4. **Folder failure handling:** Skip failed folder + continue + loud warning
5. **Thumbnail path security:** Restrict to currently-selected photo directory only
6. **Tests:** Targeted pytest for undo system + security fixes only

## Key Implementation Notes
- Thumbnails: use `exiftool -b -ThumbnailImage` for RAW files (100x faster than Pillow on full RAW)
- Leaflet.js: vendor the library (not CDN) for offline usage
- Undo log: disk-based in `.photoshell/operations.jsonl` (not in-memory)
- Keyboard shortcuts: check `document.activeElement.tagName` before processing (skip in inputs)
- Presets: sanitize names to `[a-zA-Z0-9_-]`, store in `.photoshell/presets/`
- Pipeline view: reuse existing Mermaid integration (already loaded in docs modal)
- Elapsed time per step in log output: "[Step 3] Blur Detection — completed in 47s"
