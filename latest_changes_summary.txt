Latest updates in PhotoShell include a new `annotate_photos_with_ollama.sh` workflow that runs Ollama per image and replaces generated technical descriptions into `EXIF:ImageDescription` and `IPTC:Caption-Abstract` while leaving `EXIF:UserComment` unchanged, with support for three input modes (directory scan, single file via `--file`, and file list via `--list`), plus prompt selection via prompt file IDs and dedicated documentation/README coverage.
