Latest updates in PhotoShell include a new `annotate_photos_with_ollama.sh` workflow that runs Ollama per image and appends generated technical descriptions to both `IPTC:Caption-Abstract` and `EXIF:UserComment`, with support for three input modes (directory scan, single file via `--file`, and file list via `--list`), plus new dedicated documentation and README coverage for the script and its safety/usage rules.
