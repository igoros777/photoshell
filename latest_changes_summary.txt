Latest updates in PhotoShell include a new `search_exif_iptc.sh` workflow for metadata text search across supported image/raw/video files with selectable EXIF/IPTC fields, media-type filters, and recursive/non-recursive scan modes, plus dedicated documentation and README coverage; the EXIF field set now follows a real-world sample profile (including tags like `UserComment`, `ISOSpeedRatings`, `LensInfo`, and `GPSVersionID`), sample-style field aliases are normalized (for example `User Comment` and `White Balance`), and `UserComment` matching was fixed by correcting `exiftool` invocation and applying explicit EXIF/IPTC UTF-8 charset decoding.
